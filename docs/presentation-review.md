## 남은 제한 / 백엔드 전달 사항
- 로컬 수정본의 실서버 로그인은 403. 백엔드 CorsConfig는 https://injecapstone.com만 허용합니다. localhost/127.0.0.1 및 필요한 LAN 개발 출처 허용은 백엔드와 협의해야 합니다. Origin 위조나 보안 우회는 적용하지 않았습니다.
- `.env.development.local`은 Git 제외 로컬 설정으로 실제 API proxy 대상과 OAuth 시작 주소, 현재 배포와 같은 AI 시연 설정을 지정했습니다. 서버의 CORS 허용 전에는 로컬 실제 로그인이 거부됩니다. OAuth 성공 콜백은 현재 배포 도메인으로 돌아갑니다.
- 실제 물리적 연결 단절은 브라우저 navigator.onLine/online/offline 이벤트로 감지합니다. 서버만 중단된 5xx·CORS 오류는 인터넷 단절로 오인하지 않습니다.
- 브라우저에서 아직 앱을 받지 않은 상태의 오프라인 첫 방문/강력 새로고침까지 지원하는 PWA/service worker는 추가하지 않았습니다. 이미 로드된 앱에서의 감지·복귀를 구현했습니다.
- 로컬 브라우저 검증은 저장소 밖의 대체 응답/연결 이벤트 도구를 사용했습니다. 실제 영상 파일·실제 AI·실제 계정 신규 가입·재연결 후 서버 인증까지의 종단 검증 및 실기기 태블릿 테스트는 별도입니다.
- npm audit에서 기존 잠금 파일의 개발 도구 의존성(minimatch 경유) moderate 12건이 보고됩니다. 강제 업그레이드로 시연 환경을 바꾸지 않았습니다. high/critical은 0건입니다.
- Windows가 원본 .git 쓰기를 거부해 원본은 과거 feature 브랜치 메타데이터가 남아 있습니다. 소스와 의존성은 최신 기준으로 동기화했습니다. 검토용 복사본에는 최신 기준 + 이번 수정만 남았습니다. outputs의 정렬 실행 파일은 파일 체크섬·백업·원격 SHA를 검사한 뒤 새 로컬 브랜치와 인덱스만 정렬하며, 소스 파일은 바꾸거나 커밋/푸시하지 않습니다.
