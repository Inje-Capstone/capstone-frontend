# 백엔드·AI 연동 현황 — 2026-11-21

## 연결된 기능

- 로그인·회원가입·OAuth 교환, 온보딩, 내 정보와 사용자 설정은 Spring API를 호출합니다.
- 퀴즈 문제 조회·채점·풀이 기록·통계는 Spring API를 호출합니다.
- 경기·용어·카드·장면·매치업·챗봇은 Spring `/api/ai/**` 중계를 통해 AI API에 연결합니다. 요청에 로그인 JWT를 포함합니다.
- 시연 경기·용어 seed·가상 AI 응답은 제품 소스에서 제거했습니다. 서버 오류는 그대로 오류 UI로 전달합니다.

## 확인 또는 추가 연결이 필요한 항목

- **영상 주소:** AI의 경기 응답에는 영상 URL이 없습니다. 서버가 주소를 제공할지, 프론트 설정으로 제공할지 합의가 필요합니다. 연결 전에는 실제 영상이 없는 경기를 재생할 수 없습니다.
- **풀이 기록:** 백엔드 API는 최신 10건과 정답/오답 필터를 지원합니다. 현재 화면은 5건/10건을 표시합니다. 풀이 상세 API와 `attemptId`는 명세에 있지만 화면에서 아직 사용하지 않습니다.
- **퀴즈 추가 기능:** 날짜별 문제, 해설, 보상, 중복 제출 정책은 현재 화면에 연결하지 않았습니다. 확정 API와 정책을 받은 뒤 연결합니다.
- **상점:** 상품, 가격, 잔액, 구매, 보유 아이템 API가 확인되지 않아 가상 상품 목록을 제거했습니다.
- **사용자 설정:** 관심 카테고리, 복습 설정, 영상 이어보기 일부는 현재 브라우저 저장입니다. 서버 동기화 범위를 합의해야 합니다.
- **비밀번호 재설정:** 최신 프론트는 API 호출 코드를 갖고 있으나 현재 백엔드 OpenAPI에서 경로를 확인하지 못했습니다. 실제 경로·DTO·상태 코드를 확인해야 합니다.
- **OAuth 로컬 복귀:** 백엔드 OAuth 최종 복귀 URL이 현재 개발 주소를 허용하는지 확인해야 합니다.

API 규격이 확정된 항목은 서비스 경계에서 서버 DTO를 화면 모델로 변환합니다. 확인되지 않은 경로·필드·응답은 프론트에서 만들어 넣지 않습니다.
