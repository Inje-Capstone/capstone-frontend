## 반영한 화면 변경

1. 로그인 하단에 관리자 전용 로그인 버튼을 추가했습니다. 연결 주소/API가 미정이므로 클릭 시 준비 중 안내만 표시합니다.
2. 챗봇 대화 영역을 항상 펼쳐두고 접기, 빈 대화 힌트, 입력 placeholder를 제거했습니다. `data-form-hints="off"`로 챗봇을 공통 폼 툴팁에서 제외했습니다. 로그인은 형식 오류 안내만, 회원가입은 기존 안내를 유지합니다.
3. 시연 플레이어의 재생/일시정지 아이콘을 동일한 SVG viewBox·크기로 통일했습니다. 실제 video의 브라우저 기본 controls는 유지합니다.
4. 사전 상세의 난이도 선택을 제거했습니다. 본문은 기존 API의 BEGINNER 설명을 사용하고 별도 쉬운 설명을 유지합니다.
5. 사전 정렬 문구는 가나다순으로 고정하고 화살표만 전환합니다.
6. AI 카드 제목은 감지된 키워드로 유지하며 키워드와 이전 목록에는 용어명만 표시합니다. 카드의 시간 표시는 제거하고 영상 탐색 막대와 이전 용어 선택 시 장면 이동은 유지합니다.
7. 퀴즈는 왼쪽 문제/오른쪽 풀이 기록을 8:2로 배치합니다. 650px 이하에서는 문제 다음에 기록을 세로 배치합니다.
8. 헤더·마이페이지 프로필은 응원팀 엠블럼을 기본 사용합니다. 팀이 없거나 이미지 오류 시 기본 프로필을 표시합니다. `ProfileAvatar`는 별도 `image: {src, alt}`를 받을 수 있어 추후 상점 캐릭터·다른 이미지로 교체할 수 있습니다. 이미지 업로드·구매·선택 저장 API를 새로 가정하지 않았습니다.
9. 스플래시 SVG를 viewport 높이에 맞춰 채우고 좁고 긴 창에서도 양옆 실밥이 상하단까지 이어지게 조정했습니다.
10. 설명 펼치기/접기는 같은 CTA 버튼을 사용합니다. 기존 텍스트 액션은 공통 테두리 버튼 형태로 통일하고 이동 링크는 링크 의미를 유지하면서 버튼 스타일을 적용했습니다.
11. 온보딩·마이페이지 응원팀 선택은 제공받은 10개 구단 엠블럼과 전체 구단명을 표시합니다. NONE은 별도의 아직 없어요 선택지로 유지합니다.

## 추가 개발/협의가 필요한 부분

- **퀴즈 추가 기능**: 기본 문제 조회·채점은 PR #10에 따라 연결했습니다. 날짜별 퀴즈, 정답 선택지, 해설, 보상은 현재 서버 DTO에 없으므로 추가 계약이 필요합니다. `QuizRepository`는 남아 있는 과거 모델이며 현재 퀴즈 화면에서는 사용하지 않습니다.
- **풀이 기록**: 운영 API에는 최근 최대 20건 조회와 통계가 있지만 프론트 #16까지는 미연결입니다. 이번 작업은 승인된 PR 범위와 UI 결합에 한정하므로 추가 연결은 하지 않았습니다. 날짜 범위/페이지네이션과 submittedAt의 시간대 정책은 별도 확인이 필요합니다.
- **관리자**: USER/ADMIN enum 및 JWT role claim은 있으나 별도 관리자 로그인/관리 API와 관리자 권한 경로 규칙은 현재 컨트롤러에서 확인되지 않습니다. 프론트 버튼만으로 관리자 권한을 부여하지 않습니다.
- **로컬 CORS/OAuth**: 현재 CorsConfig는 https://injecapstone.com만 허용합니다. 운영 API에 localhost:5173 Origin으로 OPTIONS를 보내면 403입니다. 실제 사용할 개발 출처와 OAuth 최종 복귀 주소를 서버에서 허용해야 합니다.
- **프로필 커스텀 이미지**: 현재는 제공한 팀 이미지의 정적 매핑으로 충분합니다. 추후 임의 이미지/상점 캐릭터 선택을 영속화하려면 조회·선택·이미지 URL 등의 계약이 필요합니다.
- **회원 탈퇴/비밀번호 변경/상점/AI 중계**: 현재 확인한 develop 전체 컨트롤러 및 운영 OpenAPI에는 해당 API가 없습니다. 외부 AI의 운영 상태나 실제 영상 정합성은 이번 백엔드 확인으로 검증되지 않았습니다.
