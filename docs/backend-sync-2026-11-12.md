## 바로 개발해 반영한 범위

기존 8:2 배치를 유지하고 퀴즈 화면 우측에 서버 기록을 표시합니다.

| 기능 | API/규격 |
|---|---|
| 최근 풀이 기록 | GET `/api/quizzes/attempts?limit=20` |
| 정답만 | `correct=true` |
| 오답만 | `correct=false` (false도 쿼리에 포함) |
| 조회 개수 | 5/10/20 선택. 서버 허용 범위는 1~20 |
| 전체 통계 | GET `/api/quizzes/attempts/summary` → totalCount/correctCount/incorrectCount |
| 제출 후 갱신 | 채점 성공 후 기록과 통계를 다시 조회 |

- 기록은 questionId, selectedOptionId, correct, submittedAt만 사용합니다. 읽어온 문제 목록에 문항이 있으면 문항·선택지 내용도 함께 표시합니다. 기록에 없는 해설/정답 선택지/포인트를 생성하지 않습니다.
- 전체 통계는 전체 계정의 누적값이며 필터 결과나 최근 20개를 합산한 값으로 대체하지 않습니다.
- 기록은 서버가 정렬한 최신순을 유지합니다. submittedAt은 offset 없는 LocalDateTime이므로 시간대를 추측해 변환하지 않습니다.
- 독립 로딩·오류·재시도·빈 결과 안내를 제공합니다. 기록 오류가 현재 문제나 채점 결과를 지우지 않습니다.
- 필터 변경 시 진행 중인 이전 조회를 AbortSignal로 취소합니다.
- `src/types/quiz.ts`에 현재 서버 DTO 타입을 추가하고 `quizService`에서 응답 구조와 조회 범위를 확인합니다.
- 저장소 밖의 5174 테스트 도구도 같은 규격의 가상 기록·통계를 제공하도록 갱신했습니다. 실제 서버와 별개입니다.
